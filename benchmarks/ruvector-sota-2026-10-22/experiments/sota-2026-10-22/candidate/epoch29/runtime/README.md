Original core2.3.0 (wrapper0.1.33/platform0.1.31) and the pinned BGE encoding runtime are the only intended model/native dependencies. No TypeSafe2.4 addon is admitted here.

The launch command is:

```sh
PYTHON -I -B PROJECT/experiments/sota-2026-10-22/candidate/epoch29/runtime/launch.py --scope S29 --plan PROJECT/experiments/sota-2026-10-22/epoch29/plan.json --admission PROJECT/experiments/sota-2026-10-22/epoch29/NATIVE_ADMISSION.json --expected-plan-sha SHA256

The original ten core/BGE assets and all17,498 pinned installed-wheel members are byte-verified without importing their modules. The manifest extends the E27 runtime lock with `wheel_members_reference_path`, `_sha256` and `_count`.

The launcher reserves `ATTEMPT_RESERVATION.json` by exclusive creation and fsync before Popen, records the actual returned PID/startticks/PGID/SID and allows one owned session. Work ends at585seconds from invocation, leaving15seconds within the600second total for owned cleanup and sealing. Lease expiration can shorten the deadline. Cancellation enters the same cleanup path. TERM/KILL applies only after physical process/session identities are checked. Any failure burns the reserved slot; incomplete or uncertain starts never permit a retry.

Before the Python worker executes, its preexec hook pins CPU0,1, enables no_new_privs, installs an inherited Linux x86_64 seccomp filter denying sched_setaffinity203 and its x32 variant with EPERM, and fsyncs `worker-cpu-preexec.json`. It kills a wrong syscall architecture and permits other syscalls. Every later Python/native/Node thread and descendant inherits this narrow resource boundary. Worker/Node must not call setaffinity or install a second guard. Actual denied affinity syscall totals are unobserved and remain null. Synthetic EPERM counts are separate proof of guard behavior, not actual model operation counts.

Python and Node public network APIs are interposed with persistent fatal accounting. Exact stdin/stdout/stderr pipes are allowed in Node. DNS, TCP, UDP, HTTP and fetch attempts are denied. This is API interposition, not kernel network syscall isolation; compiled native activity and bypasses are not represented as observed network syscall counts. The Node preload verifies frozen source/runtime/bundle bytes and inherited CPU status before permitting exactly one load of the original core addon. It returns native exports unchanged and wraps no model, ANN or version API.

`execution.json` preserves actual raw/partial/pending byte seals, launcher errors, cleanup errors and observed resources. `raw_operation_counters_source` is `raw.json`, `raw.partial.json` or `UNKNOWN`; only a parsed final counters object yields `operation_counts_complete:true`. A checkpoint has an unknown backend tail and cannot claim a complete run. Missing raw counters remain null, never fabricated zeros. Malformed final bytes and known partial counters are retained together. The scorer/stager must bind the selected original artifact and discriminator, reject hidden valid final output, and retain any incomplete-result failures independently of publication consistency.
