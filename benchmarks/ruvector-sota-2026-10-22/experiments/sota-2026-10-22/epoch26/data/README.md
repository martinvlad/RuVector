# Original ContractNLI project DEV input bank

These inputs contain eight original ContractNLI TRAIN documents, each paired with three fixed original hypotheses (24 cases). The documents are 437, 614, 194, 174, 256, 490, 317 and 196; the hypotheses are nda-17, nda-7 and nda-3. Selection used document ID metadata and a frozen SHA256 draw before source text, labels or measurements. No labels are included in this directory's input bank.

Source: [stanfordnlp/contract-nli](https://github.com/stanfordnlp/contract-nli/tree/eced6528dd3c1d14d73f9a87df8f7bdbc03126f9), revision `eced6528dd3c1d14d73f9a87df8f7bdbc03126f9`. The original `train.json` has 7,608,211 bytes and SHA256 `dbceb356cd6203b35b27be94a5fa85e499a81c34c42c89ad53060b39f0257ba5`.

Transformations: select eight original TRAIN documents and three original hypothesis definitions; preserve their complete text exactly; add project case identifiers, input-only metadata and canonical SHA256 identities; encode as a JSON input bank. Canonical input hashing uses UTF-8 JSON for `{document: exact_document, hypothesis: exact_hypothesis}`, with sorted keys, compact separators, Unicode preserved and nonfinite numbers forbidden. Retrieval may select source spans for the reader; exact characters, UTF-8 offsets, retained and omitted numerical literals and the complete original document remain separately recorded. Source fields are not normalized for inference. Casefold/whitespace normalization is used only for duplicate/alias checks.

These cases are permanently exposed project DEV. The selected classifier's supervised training, evaluation, checkpoint selection and calibration data identities are unresolved. Project-unused documents therefore do not establish independent heldout generalization. There is no official score, benchmark acceptance, fresh confirmation or champion promotion from this diagnostic. TRAIN fitting and calibration are empty; CONF is empty and held. All prior exposed banks retain their old roles, and reserved confirmation identities remain unconsumed.

The frozen input builder parses the complete public annotated source JSON into RAM but reads only selected document text and hypothesis definitions. This is logical field isolation, not OS enforced label secrecy. The independent scorer may join only the 24 predetermined original annotation choices, after all 72 matched-arm outputs are complete, sealed and the owned worker group is closed. An incomplete or failed worker does not permit gold projection or complete-corpus metrics.

The scorer replays native three-way logits and uncalibrated unit-temperature probabilities, reports 24-case accuracy, per-class counts and correctness, confusion matrices, per-document outcomes, sum-of-three-class Brier loss and NLL clipped at 1e-12 with clip counts. The raw-only auditor checks source provenance, observed native order, lexical and positional controls, counters, errors, timing and runtime closure without labels or ML execution. Diagnostic qualification and artifact integrity are distinct from benchmark acceptance; benchmark acceptance and promotion remain false even if descriptive diagnostic gates pass. A retrieved-context NotMentioned class prediction does not prove absence from the full legal agreement.
