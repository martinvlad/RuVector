# One larger pretrained typed reader over native RuVector evidence

This epoch tests one 24-layer/1024-hidden pretrained DeBERTa-v3-large MNLI/FEVER/ANLI/LingNLI/WANLI reader. Its exact converted revision and six assets are pinned in model-choice.json and model-assets.lock.json. This is a higher-capacity architecture than the rejected base9 reader; no legal-quality or runtime gain is assumed. It is a different three-way checkpoint from the failed binary large7 model. No learned head, fitting, calibration, temperature or threshold grid is used.

Actual native RuVector/BGE evidence uses the exact reviewed epoch6 partition,40 ranked-anchor and same-paragraph neighbor packing policy, old policy tokenizer and raw512 pair cap. Lexical and positional arms use the same model, features, context budget and decoder. Native104 sees the identical primary packed excerpt; this is not a full submitted-champion rerun. Historical top2 arm names are aliases for variable-unit bounded packing.

The decoder retains all pretrained classes: raw E0/Neutral1/C2; canonical E,C,NotMentioned. Yes=P(E), No=P(C)+P(N), temperature1, No on exact .5 tie. Neutral is never discarded or interpreted as a proof of evidence absence. All inference inputs contain only state/questions. Retrieved annotation/number retention is an audit of source characters, not evidence sufficiency, numeric truth or legal reasoning. Future ClaimBench retrieval must remain within supplied10-K excerpts; misses never prove insufficient evidence.

The active tokenizer differs in JSON byte identity from the frozen policy tokenizer. All vocabulary pieces/IDs and float32 scores match; defaults include truncation512, which runtime explicitly disables. This metadata fact is not a proof of universal tokenization equality. Source preflight and runtime independently enforce raw512 for both tokenizers, no padding/clipping, and whole claim preservation. The new tokenizer affects decoder IDs only; no packing grid is introduced.

Fresh DEV24 is frozen before the single exact model choice; existing CONF48 remains project-model-unused and conditional under the parent scorer. TRAIN/calibration are empty.
