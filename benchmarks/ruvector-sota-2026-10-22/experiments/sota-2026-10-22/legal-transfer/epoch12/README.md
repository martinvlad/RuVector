# Epoch12 frozen data and official-source refresh

This is an internal, source-licensed three-predicate original ContractNLI NDA pilot. It is not a result on full LegalBench, current JevBench300 or ClaimBench. The data worker ran no model, native inference, fitting or actual benchmark scoring.

The fixed study compares pretrained FP32 and quantized source fidelity without choosing the primary precision from observed outcomes. TRAIN sanity has six queries from two already-exposed epoch10 TRAIN groups, selected once by text/ID-only SHA256 ranking from the prior 24-group TRAIN pool. It is diagnostic data, not fresh generalization or training-feature extraction. No fitting, calibration, threshold search or precision selection is permitted. DEV has 24 queries from eight previously unused original-train groups. The predicate set is fixed to nda-17, nda-7 and nda-3 for both roles. The role file froze before selected annotations were projected, and the data contract froze before the final model choice.

The original-train registry contains 423 documents: 173 previously exposed groups, 16 reserved confirmation groups and 234 unreserved eligible groups. One new fixed source-text/ID-only ranking selects eight DEV groups, leaving 226 unreserved. Selection uses no label, outcome or document-length stratification and has no redraw. After any phase1 process attempt, all eight declared DEV groups become permanently exposed, conservatively yielding 181 exposed groups even if the process stops during TRAIN sanity. The reused TRAIN groups add no new exposure. This conservative retirement rule is separate from actual request completion counts.

Existing epoch9 confirmation48/16groups remains the same reserved bank, SHA256 `850b1f1d61d81ee83227ff3e62696011a9571b9349cbf926d61243bfacadbf50`. Its projection file was byte-hashed, never JSON-parsed here. Only its separate label-free identity allowlist was copied. Reserved annotations were not inspected, selected or fitted. A phase2 invocation attempt retires the entire confirmation bank even if no request succeeds. Public-source availability does not make a test sealed, and unknown upstream pretraining overlap or fuzzy document versions remain limitations.

`build.py --source /path/to/hash-verified/original-train.json --output-dir /unused/output` reconstructs both role projections and their metadata-only allowlists using the builder, eligibility registry, draw plan and frozen role file. `validate.py` verifies exact frozen bytes and rejects 12 boundary mutations. `isolated-replay-validation.json` records four byte-identical output files from a clean reconstruction. All old public183, easy48, Legal96, original-dev confirmation96 and prior original-train exposed groups remain DEV forever.

Only `input.state` and `input.questions` reach model features. The TRAIN example ID may be checked for allowlist membership and one-use enforcement; it is never a model feature. Gold labels, annotations, source groups, split roles and provenance are excluded from inference. The standard `input_sha256` uses UTF-8 JSON with sorted keys, compact comma/colon separators, `ensure_ascii=False` and `allow_nan=False`. TRAIN metadata additionally binds the raw UTF-8 state, canonical sorted questions, and the compact unsorted state/questions wire object. Binary gold is Yes only for Entailment; Contradiction and NotMentioned map to No, with the original three-way labels retained for diagnostics. Document groups are the bootstrap unit.

`refresh.py` completed exactly three read-only official GETs, without retries: the JevBench open-weights board, the official ClaimBench page and its freshly discovered aggregate JSON. Observed Jev-class Capability leader was Chon-1.0-12B at 85.3. ClaimBench decision/d1-ultra had 100.0%, with four language models also at 100%. These are publisher aggregate observations, not RuVector scores or placements. The original submission7FEA2738 queue position115 was never rank; root separately checks publisher notices. Current JevBench300 questions/scorer and full ClaimBench questions/scorer/license/submission access remain unverified. No ClaimBench pilot ran or score is invented. Future ClaimBench retrieval must remain within supplied10-K excerpts; a retrieval miss cannot establish insufficient evidence.

`publication-files.json` is the explicit public allowlist. Raw official HTML/aggregate payloads, complete public examples, nested reconstruction directories and Python caches are excluded. Root separately freezes model/runtime/scorer revisions, executes bounded native batches and obtains independent acceptance or rejection.
